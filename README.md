# AyuCompiler 💻

**A Modern, All-in-One Online Coding Workspace**

AyuCompiler is a modern, browser-based coding workspace designed to help developers write, execute, debug, experiment with ideas, and preview web projects in one place. With a professional code editor, an interactive console, live web previews, workspace management, reusable starter templates, and **Ayu AI assistance**, it provides a streamlined environment for learning, development, and rapid prototyping.

Built with a focus on performance, usability, and a clean developer experience, AyuCompiler brings essential coding tools together in a single workspace.

## 🚀 Getting Started

Follow these steps to run AyuCompiler locally.

### Prerequisites

Make sure you have the following installed:

- [Node.js](https://nodejs.org/) — version 18 or higher recommended
- npm (included with Node.js) or Bun
- Git
- A modern web browser

### 1. Clone the Repository

```bash
git clone <YOUR_GITHUB_REPOSITORY_URL>
```

### 2. Navigate to the Project Directory

```bash
cd ayu-workspace
```

Replace `ayu-workspace` with your actual repository directory name if it differs.

### 3. Install Dependencies

Using npm:

```bash
npm install
```

Or using Bun:

```bash
bun install
```

### 4. Start the Development Server

Using npm:

```bash
npm run dev
```

Or using Bun:

```bash
bun run dev
```

Open the local URL displayed in your terminal to access AyuCompiler.

### 🏗️ Production Build

Create an optimized production build:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

**Note:** The commands above assume the project includes the corresponding scripts in `package.json`.
